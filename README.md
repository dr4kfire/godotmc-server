# Dot - A Minecraft Java edition Godot server
This is an implementation of the minecraft java server made completly in godot. 
The main focus is to allow easier ways for creating minecraft plugins, servers 
and experiences. **NO AI** was used in creation of this project.

### 📦 FEATURES:
These are the things that are implemented right now
- none :P

### 🎯 ROADMAP:
This is a (somewhat chronological) list of the next features
- Server listing information
- Joining and leaving
- Sending world data
- Generating worlds

### 🌱 FUTURE PLANS:
These features are what I want this project to grow into in the future!
- Full java server implementation
- Plugins support (Bukkit, Spiggot, Paper, Dot)
- Extensive customization options (Performance, etc.)
- Bedrock support (cross-platform)
- Modular design
- ... and many more!
